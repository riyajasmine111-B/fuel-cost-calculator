# Fuel Cost Calculator

This is a simple C program that calculates the amount of fuel required for a trip and the total fuel cost.

## What the program calculates

- Total distance
- Vehicle mileage
- Fuel price
- Fuel required
- Total fuel cost

## How it works

The program takes the total distance, mileage, and fuel price as input.

It then calculates:

**Fuel Required = Distance / Mileage**

**Total Fuel Cost = Fuel Required × Fuel Price**
